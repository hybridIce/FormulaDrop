截图。粘贴。复制。

在 Mac 或 Windows 桌面 App 中，点击“截图”立即打开框选截图，拖动鼠标选中公式，松开后自动识别。按 Esc 可取消。首次使用如提示屏幕录制权限，请在系统设置中允许启动本工具的应用，然后重启工具。

Mac 按 ⌃ + ⇧ + ⌘ + 4，框选公式并复制到剪贴板，回到此页按 ⌘ V。

也可拖入图片或点击上传。图片上拖动可框选裁剪区域，然后点击“识别公式”。

修改 LaTeX 源码会实时更新预览。可以复制 LaTeX、行内 / 块级 Markdown 或 MathML。

“复制到 Word”写入富文本 MathML，兼容性取决于 Word 版本。如果粘贴未生成公式，请下载 .docx 并复制其中的原生公式；支持 LaTeX 输入的 Word 也可以在公式框内粘贴 LaTeX。

本地模型主要面向单个印刷公式。手写、整页文字、模糊图片和复杂矩阵可能识别不准确，请核对结果。历史仅保存最近 20 条公式文本，不保存图片。
